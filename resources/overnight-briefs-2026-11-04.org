** Shared context (prepend to every brief)
BrainTool is a Chromium MV3 extension (=extension/=) plus a jQuery/treetable app (=app/=) that uses org-mode files as its data store. Plain ES modules: no build step, no bundler. Read =CLAUDE.md= and =resources/BrainToolDesign.org= first. Ignore =versions/=: it holds old shipped snapshots. Run =npm run lint= before every commit; it must show 0 errors. Work on your own branch, open a PR, and do not merge. In the PR description list anything you couldn't verify. You have no access to Tony's Google Drive, license or Stripe accounts, or his real browser, so don't try to test those flows. Record them as manual checks in the PR.

The unreleased work since 1.3.2 (the headline of the coming 1.4):
- *Session Manager:* a live "Session" subtree shows the current browser windows, tab groups and tabs, reconciled with the browser (=app/sessionManager.js=, =app/BTSessionNode.js=). It can be shown or hidden from a Settings toggle (=BTShowSession= pref), and deleting the session root closes it.
- *Drag and drop between the two trees:* drag a topic into the session tree to open it; drag a session tab or group onto a topic to save or re-file it. Rule: a link can't sit at top level; it needs a parent topic.
- *Smaller items:* undo works after a delete-to-Trash (Option/Alt+Z); sticky-tab notes survive navigating away and back; the popup recognises tabs dropped into managed tab groups and reflects title edits; links and groups open in a real window on Vivaldi; dark-mode contrast fixes. The AI Summarizer experiment was removed; it was never public, so don't mention it.
